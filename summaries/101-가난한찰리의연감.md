# 101. 가난한 찰리의 연감 (찰리 멍거)

## 들어가며
피터 코프먼이 엮은 찰리 멍거(1924~2023)의 연설·강연 모음. 제목은 벤저민 프랭클린의 『가난한 리처드의 연감』에서 따왔다. 핵심 주제는 여러 학문의 핵심 아이디어를 모아 '사고의 격자(latticework of mental models)'를 만들라는 것.

## 1부. 멍거는 누구인가
변호사에서 투자자로, 버핏과의 동업, 시즈 캔디 인수 사례(좋은 회사를 적정 가격에).

## 2부. 사고의 격자
망치를 든 사람에겐 모든 게 못으로 보인다 / 능력의 범위 / 거꾸로 생각하라(Invert, always invert) / 안전 마진.

## 3부. 인간 오판의 심리학
보상·처벌 초강력 반응, 좋아함/싫어함, 일관성·헌신, 호혜성, 사회적 증거, 손실 회피, 질투, 인지 부조화, 확증 편향, 과신, 앵커링·대비 오류, 권위 복종, 휴리스틱 오류, 락폴라루자 효과(여러 심리 경향이 한 방향으로 겹칠 때 효과 폭발).

## 4부. 투자와 사업 원칙
소수 종목 집중, 좋은 회사를 적정 가격에, 해자(moat), 기다리는 인내, 복리, 신뢰와 정직, 회계 숫자 경계.

## 5부. 삶의 지혜
존경할 사람을 따르라, 평생 학습, 가족·우정, 작은 부정직도 경계.

## 6부. 실수 사례
살로먼 브라더스 사건, 싸게 사서 후회한 회사들, 대학 교육의 한계.

## 7부. 멍거식 결정 체크리스트
능력의 범위 안인가 → 인센티브는? → 거꾸로 생각했나 → 어떤 심리 경향에 빠졌나 → 여러 모델로 봤나 → 안전 마진 → 반대 의견 검토 → 기다릴 수 있나.

## 고등학생용 핵심 5줄 요약
1. 여러 분야의 지식을 모아 사고의 격자를 만들어라.
2. 거꾸로 생각하라. 망하는 법을 피하면 반은 이긴다.
3. 사람은 쉽게 착각한다. 심리 경향을 알면 실수가 줄어든다.
4. 잘 아는 범위 안에서, 좋은 것을, 적당한 값에, 오래 기다려라.
5. 평생 배우고 정직하게 살아라. 신뢰가 가장 큰 자산이다.

## 한 줄 인사이트
똑똑해지려 애쓰기보다 어리석음을 피하는 법을 먼저 배우면, 시간이 나를 부자로 만든다.
